## SEO Best Practices

### On-Page SEO
- [ ] Title tag: Primary keyword + brand (max 60 chars)
- [ ] Meta description: Compelling, includes keyword (max 155 chars)
- [ ] H1: Primary keyword
- [ ] H2/H3: Secondary keywords
- [ ] Image alt text: Descriptive with keywords
- [ ] Internal links: 3-5 per post
- [ ] External links: 1-2 authoritative sources

### Content Quality
- [ ] 1500+ words minimum
- [ ] Short paragraphs (2-3 sentences)
- [ ] Bold key terms
- [ ] Numbered lists for steps
- [ ] FAQ section
- [ ] WhatsApp CTA

### Technical SEO
- [ ] Mobile-friendly
- [ ] Fast loading
- [ ] SSL enabled
- [ ] XML sitemap
- [ ] Robots.txt
- [ ] Canonical URLs
